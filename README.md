# Source Player

The IPTV player for Windows and Mac. Like TiviMate, built for the desktop.

[**Download the latest release**](https://github.com/source-player/source-releases/releases/latest) · [Website](https://sourceplayer.app) · [Support](https://sourceplayer.app/support)

![The live TV guide](https://sourceplayer.app/og-guide-2.png)

- **Live TV with a real guide.** Channel logos, what's on now and next, favorites, XMLTV.
- **Every movie and series, with posters.** Resume where you stopped.
- **One search across every provider.**
- **Plays what browser players can't.** Built on mpv: 4K, HEVC, AV1, TrueHD and DTS-HD, with HDR tone-mapped to fit your screen.
- **Picture-in-picture, Chromecast, AirPlay, local folders.**
- **Free. No account. No tracking.**

Works with Xtream Codes logins and M3U/M3U8 playlists. Source doesn't come with channels; bring your own subscription.

Windows 10/11 (64-bit) · macOS 11+ on Apple Silicon
